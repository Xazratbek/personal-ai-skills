# AI-slop tells (with sources)

Sources: [Opus — 12 tells of AI video](https://www.opus.pro/blog/ai-slop-aesthetic-12-tells) · [Green Frog Labs — AI video quality checklist](https://greenfroglabs.com/blog/ai-video-quality-avoid-slop-appearance) · [DetectVideo — AI slop](https://detectvideo.ai/ai-slop/) · [Coursera — What is AI slop](https://www.coursera.org/articles/ai-slop) · [Impeccable anti-patterns](https://www.mintlify.com/pbakaus/impeccable/concepts/anti-patterns) · [Anti-AI-slop ban list](https://github.com/Laith0003/ux-skill/wiki/Anti-AI-slop-ban-list)
(Most sources are vendor/dev blogs: treat specifics as informed opinion, not settled research. One cited "83 % of viewers spot AI motion" figure was not verified.)

| Tell | What it looks like | Counter-measure |
|---|---|---|
| Modular script | Same arc, same hook, same ending; subject can be swapped without changing the text | Distinct hook archetype + concrete local details + unique closing line per video |
| Generic claims | Hype adjectives, claims that fit any product | Checkable facts only; named source or real UI |
| Default aesthetic | Purple/violet gradients, cyan on dark, blurred glows, glassmorphism, gradient text, emoji headings, centred everything, default fonts | Brand-specific palette/type/layout, flat colour, grain, hard shadows, asymmetry |
| Silky weightless motion | Mathematically smooth moves, floating, no weight transfer, no micro-jitter | Anticipation/overshoot/settle, organic drift, varied easing and stagger |
| Flat uniform light/colour | Same diffuse light, over-saturated grade | One restrained grade, real specular/sweep lights, device shadows |
| No camera variety | No depth, no movement, same framing | ≥4 compositions, ≥1 deliberate camera move, per-scene camera signatures |
| TTS plateau / no breaths | Metronomic delivery, no emphasis, no breaths every 5–10 s | Natural voice model, per-line variation, breaths, room tone, phonetic respelling |
| Silence under voice | Only VO + music bed | Foley synced to events, ambience, ducking |
| Gibberish in-scene text | Signs/logos that look like text | Use real captured UI; keep in-scene text minimal and real |
| Hands/faces morphing | Extra fingers, melting faces | Never synthesize them; use real stock footage/photos or keep out of frame |
| Text as a crutch | Words carry the message, visuals are filler | Visuals demonstrate; text supports |
| Over-polished sterility | Perfect, airbrushed, no texture | Film grain, slight imperfection, human presence |
